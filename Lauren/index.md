## ✅ GUÍA RÁPIDA

### Paso 1: Abre la Página
```
Haz clic derecho en → index.html
Abre con → Tu navegador (Chrome, Firefox, Edge, Safari, etc)
```

### Paso 2: Prueba la Funcionalidad
```
1. Haz click en el sello rosa en el centro
2. Deberías ver corazones saliendo
3. El sello debería crecer
4. Repite 5 veces para abrir la carta
```

### Paso 3: Agregar Música (Opcional)
```
1. Descarga una canción de:
   - https://www.bensound.com
   - https://pixabay.com/music
   - https://www.freepik.com/music
2. Coloca el archivo en: assets/audio/
3. Renómbralo a: love-music.mp3
4. Recarga la página en el navegador
```

### Paso 4: Personalizar (Opcional)
```
Si quieres cambiar el texto:
1. Abre index.html con Notepad o Visual Studio Code
2. Busca el texto que quieres cambiar
3. Modifica el texto entre < >
4. Guarda el archivo
5. Recarga la página en el navegador
```

## 🎨 Personalización Rápida

### Cambiar el Título de la Carta
```
Abre index.html
Busca: <h1 class="letter-title">Para Ti 💌</h1>
Cambia "Para Ti" por lo que quieras
```

### Cambiar el Cuerpo del Texto
```
Abre index.html
Busca: <p class="letter-text">Quería que supieras...</p>
Cambia el texto
```

### Cambiar la Firma
```
Abre index.html
Busca: <span class="signature-name">Tu alguien especial</span>
Cambia por tu nombre o lo que deseés
```

### Cambiar Colores
```
Abre css/styles.css
Busca: #e91e63 (color rosa actual)
Cambia a otro código de color (busca "HTML color codes" en Google)
```

## 🐛 Si Algo No Funciona

### Paso 1: Recarga la Página
```
Presiona: Ctrl+Shift+R (Windows/Linux) o Cmd+Shift+R (Mac)
Esto fuerza una recarga sin caché
```

### Paso 2: Abre la Consola de Errores
```
Presiona: F12 o Ctrl+Shift+I
Busca errores en rojo
Si hay errores, copia el mensaje y busca en Google
```

### Paso 3: Verifica la Estructura
```
Asegúrate que:
- css/ carpeta existe
- js/ carpeta existe  
- assets/ carpeta existe
- Todos los archivos están en sus carpetas correctas
```

### Paso 4: Consulta SETUP.html
```
Abre SETUP.html en tu navegador
Tiene una sección completa de solución de problemas
```
