# 💌 Página de la Carta de Amor

Una hermosa página web interactiva con un sello de carta que crece con cada click, corazones animados y una carta que se abre después de 5 clicks.

## 📁 Estructura de Carpetas

```
Lauren/
├── index.html              # Página principal
├── css/
│   └── styles.css         # Estilos y animaciones
├── js/
│   └── script.js          # Lógica interactiva
├── assets/
│   ├── audio/
│   │   └── love-music.mp3 # Música de fondo (ver instrucciones)
│   └── images/
└── README.md              # Este archivo
```

## ✨ Características

✅ **Sello interactivo**: Haz click en el sello rosa y crece con cada click  
✅ **Corazones animados**: Corazones salen del sello en todas direcciones  
✅ **5 clicks para abrir**: Después de 5 clicks, la cartas se abre con animación  
✅ **Carta hermosa**: Incluye título, texto elegante y firma  
✅ **Corazones flotantes**: Corazones adicionales flotan dentro de la carta abierta  
✅ **Música de fondo**: Suena música de amor cuando se abre la carta  
✅ **Diseño responsive**: Se ve bien en dispositivos móviles y desktop  
✅ **Colores hermosos**: Gradientes y colores rojizos/rosas en toda la página  

## 🎵 Configuración de la Música

La página espera un archivo de audio en `assets/audio/love-music.mp3`.

### Opciones para obtener la música:

1. **Descargar música de amor libre de derechos**:
   - Visita sitios como: https://www.bensound.com  
   - Busca canciones románticas o de piano  
   - Descarga en formato MP3

2. **Usar música local**:
   - Coloca tu archivo MP3 en la carpeta `assets/audio/`
   - Renómbralo como `love-music.mp3`

3. **Cambiar el nombre del archivo**:
   - Abre `index.html`
   - Busca la línea: `<source src="assets/audio/love-music.mp3"`
   - Cambia `love-music.mp3` por el nombre de tu archivo

## 🚀 Cómo Usar

1. Abre `index.html` en tu navegador
2. Haz click en el sello rosa
3. Cada click hace que el sello crezca y suelte corazones
4. Después de 5 clicks, la carta se abre
5. Usa el botón "Empezar de nuevo" para reiniciar

## 🎨 Personalización

### Cambiar colores:
Abre `css/styles.css` y busca las variables de color o la sección `/* ========== */`

### Cambiar texto:
Abre `index.html` y busca la sección `<!-- Contenido de la carta -->`

### Cambiar fuentes:
Abre `css/styles.css` y modifica las propiedades `font-family:`

## 📝 Notas

- La música se reproduce automáticamente después del primer click (debido a políticas de navegadores modernos)
- Los corazones tienen diferentes tamaños en cada click (incrementan tamaño)
- Los colores de los corazones cambian con cada click
- La carta tiene una animación de apertura suave
